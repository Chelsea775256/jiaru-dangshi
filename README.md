# 假如当时 · 本回答仅供参考

> 知乎黑客松 2026 · 单人参赛作品
> 一个把「知乎问题」变成「可走进去的互动剧」的实验性网页。

「假如当时」想做的事很简单：你在知乎上刷到一个让人纠结的问题，不再只是滑过去看别人的回答，而是**真的走进去，做一次选择，承担一次后果**。一个问题、一次选择、回到当时。

---

## 一、它是什么

- **当事人扮演**：把知乎高热问题改编成 3 幕互动剧，你扮演当事人，每个选择点给出 A（主动面对）/ B（回避妥协）两种走向，最终落到好 / 坏 / 普通三种结局卡。
- **观点对撞**：对议论型话题，由 LLM 生成正反双方各 3 轮观点交锋，再给出三种立场的「知乎回答体」结局卡——你自己当裁判。
- **结局卡**：每张结局卡是一段 100–150 字的「假如」叙事，可以保存、分享，像一条只属于你的回答。
- **实时接知乎**：后端定时拉取知乎热榜（数据开放平台 API），热点话题直接进入「本周剧场」，并可在前端实时生成对应剧本 / 辩论。

### 为什么做这个（创作思路简述）

作者是中国人民大学艺术学院国画系的一名本科生，从零自学写网页。高中时总读不懂历史人物的决策动机——皇帝在天坛象征性耕地有什么政治意义？工业革命规模化生产为何能压低成本？直到大学买画材、参加工作、真正进入成年人社会后才慢慢明白那些选择背后的逻辑。于是想做一款能让人「回到当时」去理解不同身份境遇的产品。技术有限，先做了一个能落地的知乎版本：用 AI 把真实问题变成可体验的剧情，也希望像知乎一样，帮到正在面临类似处境的人。

## 二、适配知乎社区的场景价值

1. **问题即剧本**：知乎海量真实问题是最好的叙事素材，用户贡献的问题天然带冲突与共鸣。
2. **回答即选择**：知乎回答的本质是「我当时这么做 / 我建议这么做」，产品把它变成可交互的选择分支。
3. **热榜即剧场**：实时热榜让内容永远新鲜，热点话题即时变成可玩剧情。
4. **结局卡反向生产内容**：用户生成的结局卡可回流为知乎回答 / 动态，形成「社区提问 → 互动体验 → 产出回答」的闭环。
5. **单人 + AI 的社区示范**：一个人用 AI 工具跨越专业边界完成完整产品，本身也是知乎「跨界创作」叙事的一个样本。

## 三、技术架构

```
┌─────────────┐      HTTP / JSON       ┌──────────────────────────┐
│  前端 SPA    │  ◄──────────────────►  │   Node.js 原生服务        │
│ (原生 JS)   │   /api/stories         │   server.mjs (零依赖)     │
│ index.html  │   /api/hot             │  ├─ 知乎热榜 API 适配      │
│ game.js     │   /api/generate        │  ├─ 豆包 LLM 剧本生成      │
│ styles.css  │   /api/debate          │  └─ 通义万相 场景图生成     │
└─────────────┘                         └──────────────────────────┘
```

- **后端**：`server.mjs`，仅使用 Node.js 内置 `http` / `https` / `fs`，**零第三方依赖**，部署即用。
- **前端**：`public/` 下原生 HTML/CSS/JS，无构建步骤。
- **知乎热榜**：`GET https://developer.zhihu.com/api/v1/content/hot_list`，需 `Authorization: Bearer` + `X-Request-Timestamp` 秒级时间戳头。
- **剧本生成**：豆包（火山方舟）兼容 OpenAI 的 `/chat/completions` 接口，异步任务 + 前端轮询，避免网关超时截断。
- **场景图**：通义万相 `wanx2.0-t2i-turbo` 文本生图，异步任务落盘到 `public/assets/gen/`；OSS 链接会过期，立即本地化。
- **兜底策略**：无 LLM key 时走预置剧本（story-a/b/hot）；无万相 key 时走内置线稿图库（library.json）。

## 四、本地运行

> 无需 `npm install`（零依赖）。复制环境变量后直接启动即可。

```bash
# 1. 准备环境变量（切勿把真实密钥提交到仓库）
cp .env.example .env
#   然后在 .env 中填入 ZHIHU_ACCESS_SECRET / WANX_API_KEY / LLM_API_KEY

# 2. 启动
npm start
#   或： node server.mjs
#   默认监听 http://localhost:4173

# 3. 健康检查
curl http://localhost:4173/api/health
```

- 不填任何 key：站点仍可用，展示预置剧本（story-a / b / hot），热榜返回静态基准。
- 只填 `ZHIHU_ACCESS_SECRET`：热榜实时刷新。
- 再填 `LLM_API_KEY`：知乎问题可被实时改编为互动剧本。
- 再填 `WANX_API_KEY`：场景图实时生成（否则用内置线稿图库）。
